# MOA Content Studio

> 요즘 뭐가 뜨는지, 모아가 알려줄게. 🐑

뉴스·트렌드를 모아 AI가 분석하고, 인스타그램용 **1080×1080 7장 카드뉴스**와 캡션·해시태그를 만들어 주는 웹앱입니다.

사이트: https://pol-md5sum.github.io/sosois/

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🎬 숏폼 만들기 | 영상 여러 개 업로드 → 설명만 적으면 AI가 장면을 보고 자막·썸네일·릴스/쇼츠/클립 캡션 작성(키가 없어도 메모를 말투로 다듬는 규칙 초안) → 캡컷식 자막(흰 글씨 + 두꺼운 검은 테두리, 화면 정가운데, 글씨체 4종) + 썸네일 제목을 맨 위에 처음부터 끝까지 고정 → 9:16 1080×1920 미리보기(릴스·쇼츠·클립별 가림 영역) → 캡컷 묶음 ZIP(컷 영상·subtitles.srt·title.srt·제목 투명 PNG·썸네일·캡션·안내서) 또는 자막 입힌 완성 영상 · 캡컷식 글자 디자인 패널(템플릿 6종, 글씨체·크기·자간·행간·테두리·색·상자·세로 위치) · ✨ 자동 배치(촬영 순서·세로/가로 맞춤·목표 길이 구간 선택) · 클립별 배치·확대·위치 · 줌인 효과 · 영상 속 캐릭터 |
| 👤 계정·캐릭터 | 계정(예: MOA 모아 🐑 / 해피해피 🧸)마다 인스타 아이디·브랜드·카드 상단 태그·디자인·포즈 이미지를 따로 관리, 사이드바에서 전환. 캐릭터 등장 여부(카드뉴스 / 숏폼 썸네일 / 숏폼 영상 안) 설정, 새 계정 추가 시 캐릭터 이미지 직접 업로드 · 해피해피 계정은 육아·아기·유아용품·생활용품·생활템·아기랑 나들이 주제만(뉴스 수집·주제별 콘텐츠·트렌드·AI 원고·숏폼 캡션 모두), 카드 상단 태그도 PARENTING·BABY·LIVING·ITEM |
| 카드뉴스 형식 | 📰 뉴스 요약(7장) · 🛍️ 추천템(추천템 카드: 가격대·추천 대상·포인트) · 🎡 아기랑 가볼 곳(장소 카드: 위치·운영·요금·추천 나이) · 👶 육아 정보(단계별) — 해피해피는 주제에 맞는 형식이 자동 선택. 편집기에서 장 삭제·복제·순서 바꾸기 |
| 카드 디자인 | 🧁 소프트 정보 카드(파스텔 배경·흰 둥근 패널·칩 라벨·번호 배지, 해피해피 기본) · 💬 인스타툰 · 📰 매거진 |
| 글씨체 | 카드 제목: 프리텐다드 블랙(기본)·카페24 써라운드·수트 헤비·G마켓 산스·베이글 팻 원·가석 원, 말풍선: 고운돋움(기본), 숏폼 기본 글씨체 — 계정마다 설정 (assets/fonts/LICENSES.md) |
| 👶 오늘의 육아정보 (해피해피) | 소식(공식 발표 배지·NEW) · 월령별 가이드(이유식·수유·알레르기·구강·수면·제도 등 16개 주제, 이번 주 추천) · 내 주제함. 주제를 고르면 AI가 공식 자료를 찾아 Q&A / 주의 TOP N / 체크리스트 카드뉴스를 만들고, 출처·확인일·면책을 자동으로 넣고, 발행 전 점검(출처·표현·검수 체크·90일 재확인)을 거침 |
| 🎞️ AI 숏폼 (슬라이드형) | 카드뉴스 → 9:16 영상(전환·확대 효과) + 장면별 대본 + 인스타·유튜브·네이버 캡션 + 썸네일 + 업로드 묶음 ZIP. 촬영·편집 없이 |
| 📍 다녀왔어요 | 내 사진·영상과 메모로 "아기랑 여기 다녀왔어요!" 사진 카드뉴스·숏폼 |
| 첫 게시물 | 모아 소개 7장 프리셋 (대시보드·콘텐츠 만들기에서 한 번에 생성) |
| URL로 만들기 | 기사 주소를 붙여넣으면 AI가 기사를 직접 읽고 7장 생성 (Claude web_fetch / Gemini url_context / GPT web_search) |
| 카드 크기 | 4:5 1080×1350(기본) · 3:4 1080×1440 · 1:1 1080×1080 |
| 캡처로 만들기 | 기사 화면 캡처 이미지(최대 8장, 붙여넣기 가능)를 AI가 읽고 7장 생성 |
| 카드뉴스 디자인 (7장 전체) | 🐑 인스타툰(흰 배경·둥근 손글씨 제목·파란 강조어·손그림 박스·노란 말풍선·모아가 매 장 좌우 번갈아 등장) / 📰 매거진(사진 커버·종이 질감·굵은 타이포·노란 마커) — 설정 기본값 + 콘텐츠별 변경 |
| (이전) 첫 장 스타일 | 📷 사진 매거진 / 🐑 캐릭터 썸네일(흰 배경 + 큰 제목 + 파란 강조어 + 노란 말풍선 + 모아) / 🎨 기본 — 설정 기본값 + 콘텐츠별 변경 |
| 첫 장 커버 | 콘텐츠 생성 시 실사 느낌 AI 배경 자동 생성(GPT·Gemini 이미지) → 매거진 커버 스타일(사진 + 흰색 굵은 제목). 키가 없으면 주제 일러스트 |
| 주제별 콘텐츠 | 기획안 9개 카테고리(NEWS·TREND·AI·LIFE·MONEY·FOOD·BEAUTY·CULTURE·SHOPPING)별 뉴스, 주제별 작성 원칙·해시태그·카드 색상, 주제 1위/TOP 3 바로 만들기 |
| 오늘의 뉴스 | Google 뉴스 RSS(9개 카테고리)를 3시간마다 수집 → 같은 사건끼리 묶고 MOA 적합도로 정렬 |
| 트렌드 | Google 트렌드 한국 실시간 검색어 + 관련 기사 |
| AI 원고 | GPT / Gemini / Claude 중 선택, 7장 구조(HOOK·WHAT·WHY·SO WHAT·MOA'S PICK·LIFE/CHECK·CTA), 웹 검색 사실 확인 옵션 |
| 모델 비교 | 같은 뉴스를 여러 모델로 동시에 만들고 6개 기준으로 채점·추천 |
| 자동 디자인 | 문구에 따라 큰 제목 / 설명 / 리스트 / 큰 숫자 / 좌우 비교 / 키워드 / CTA 레이아웃 자동 선택 |
| 모아 캐릭터 | 카드 유형에 맞춰 포즈 자동 선택(14종), 말풍선, 텍스트와 겹치지 않게 배치 |
| 편집기 | 7장 목록 / 미리보기 / 편집 패널 (문구·포즈·위치·크기·글자 크기·색상) |
| 내보내기 | 카드별 PNG, 7장 ZIP(캡션 포함), 원클릭 “오늘의 콘텐츠” 3건 ZIP |
| 내 콘텐츠 | 초안·제작 완료·게시 예정·게시 완료 관리, 검색·필터, 백업/가져오기 |

## 구조

```
index.html, css/, js/          정적 웹앱 (빌드 없음)
  js/ai.js                     프롬프트·스키마·GPT/Gemini/Claude 호출 (브라우저·Node 공용)
  js/render.js                 1080×1080 캔버스 렌더러
  js/store.js                  설정·API 키·콘텐츠 저장 (브라우저)
  js/app.js                    화면
scripts/fetch-news.mjs         뉴스·트렌드 수집 → data/news.json (GitHub Actions)
.github/workflows/pages.yml    push·3시간마다 수집 후 GitHub Pages 배포
assets/moa/                    모아 캐릭터 (배경 제거본 moa.png, 원본)
```

## 설정

1. **AI API 키**: 사이트의 ⚙️ 설정에서 입력합니다. 키는 그 브라우저에만 저장되고 각 AI 회사로 직접 전송됩니다.
2. **(선택) AI 뉴스 선별**: 저장소 Settings → Secrets and variables → Actions에 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY` 중 하나를 추가하면 수집 시 AI가 MOA 적합도와 요약을 다시 매깁니다.
3. **포즈 이미지**: 설정에서 포즈별 투명 PNG를 올리면 기본 이미지 대신 사용됩니다.

## 로컬 실행

```bash
npm run news     # data/news.json 생성 (인터넷 필요)
python3 -m http.server 8000
npm test         # 네트워크 없이 파서·점수·정규화 점검
```

## 로컬 개발 (Windows 예: D:\claude\sosois)

```powershell
git clone https://github.com/pol-md5sum/sosois.git D:\claude\sosois
cd D:\claude\sosois
npm test                        # Node 22 이상
python -m http.server 8000      # http://localhost:8000
```
작업 안내는 [CLAUDE.md](CLAUDE.md), 브라우저 통합 테스트는 `npm i && npm run e2e:media && npm run e2e`입니다. 브라우저에 저장된 키·콘텐츠·영상은 주소별로 따로라서 `github.io`와 `localhost` 사이에 공유되지 않습니다.
